To establish a defensible foundation for NetShield, the two primary candidate datasets—**UNSW-NB15** and **CICIDS2017**—were evaluated across 12 rigorous data engineering, computational, and academic dimensions.

CICIDS2017 is 9x larger, requiring heavy memory and subsampling. |

## 2. Assessment of Non-Candidate Files

For complete project documentation integrity, the three miscellaneous files in `./dataset/` were audited:

1. **`network_traffic_dataset.csv` (89,709 records, 4 columns):**
   - **Verdict: REJECT.**
   - *Reason:* The target column `Activity_Type` contains only `Video_Streaming` (77,725) and `VoIP_Call` (11,984). This is an application QoS bandwidth dataset, not a network intrusion dataset. It contains no attack labels.
2. **`Midterm_53_group.csv` (394,136 records, 7 columns):**
   - **Verdict: REJECT FOR MODEL TRAINING.**
   - *Reason:* This is an unlabelled Wireshark packet capture export (`Time`, `Source`, `No.`, `Destination`, `Protocol`, `Length`, `Info`) generated during an earlier college midterm lab. It contains no ground truth labels and cannot be used for supervised learning.
3. **`output1.csv` (394,136 records, 5 columns):**
   - **Verdict: REJECT FOR MODEL TRAINING.**
   - *Reason:* A parsed subset of `Midterm_53_group.csv` with IP addresses and packet length, but without ground truth attack labels.

## 3. Final Recommendation with Academic Rationale

### **Primary Recommendation: Select UNSW-NB15 as the Primary Dataset for NetShield**

We formally recommend adopting the **UNSW-NB15 benchmark partition (`UNSW_NB15_training-set.csv` and `UNSW_NB15_testing-set.csv`)** as the primary dataset for NetShield.

### **Detailed Technical Justification:**

1. **Elimination of Class Imbalance Artifacts:**
   In CICIDS2017, benign traffic constitutes 85.5% of all records. A naive or broken classifier that simply predicts "Benign" for every single packet achieves 85.5% accuracy while detecting zero attacks. In contrast, UNSW-NB15's training set has 44.9% Normal and 55.1% Attack records. Models trained on UNSW-NB15 are forced to learn true discriminatory boundaries rather than exploiting majority-class base rates.

2. **Official Benchmark Split Eliminates Data Leakage:**
   UNSW-NB15 provides an official, universally recognized training partition (82,332 records) and testing partition (175,341 records). By adopting this partition:
   - NetShield adheres to the exact experimental conditions used in leading IEEE publications (e.g., *Joshi & Fang, 2025; Madhusudhan & Madam, 2025*).
   - Our reported metrics can be directly compared against published academic baselines.
   - It eliminates the subjective bias and cross-validation leakage common when students manually split large datasets.

3. **Computational Feasibility for a College Mini-Project:**
   The training partition contains 82,332 records and 42 features. On a standard student laptop (8 GB RAM, multi-core CPU):
   - Logistic Regression trains in $< 2$ seconds.
   - Decision Tree trains in $< 3$ seconds.
   - Random Forest trains in $\approx 25$ seconds.
   - XGBoost trains in $\approx 15$ seconds.
   - Linear SVC trains in $\approx 45$ seconds.
   This rapid turnaround allows the student team to conduct extensive hyperparameter tuning, cross-validation, and dashboard integration without experiencing out-of-memory crashes or overnight training delays.

4. **Modern, Realistic Threat Diversity:**
   UNSW-NB15 includes contemporary low-and-slow attacks (Fuzzers, Shellcode, Backdoors, Analysis) alongside volumetric DoS and Exploits. This provides rich categorical and behavioral diversity.

## 4. Secondary Recommendation: Role of CICIDS2017 in NetShield

While UNSW-NB15 is selected as the primary training and evaluation benchmark, CICIDS2017 represents a valuable secondary asset:
- **Generalization / Zero-Shot Testing Experiment (Future Scope):**
  A model trained on UNSW-NB15 can be evaluated on a subset of CICIDS2017 flow data that share common semantic features (e.g., flow duration, packet rates, byte counts) to test cross-dataset generalization.
- **Strict Prohibition on Naive Schema Merging:**
  > [!WARNING]
  > **Methodological Rule:** Never concatenate UNSW-NB15 and CICIDS2017 into a single training dataframe. UNSW-NB15 features (generated by Bro/Zeek and Argus) have fundamentally different feature definitions, aggregation windows, and column semantics than CICIDS2017 (generated by CICFlowMeter). Merging them without a mathematically proven ontology mapping creates catastrophic feature corruption.
